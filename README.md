# ЛР1 по САПР — вариант 2

Нисходящее проектирование цифрового устройства на ПЛИС Altera в Quartus II 13.0 SP1.

Распределитель сигналов на базе 4-разрядного счётчика Джонсона.

| Параметр | Значение |
|---|---|
| Последовательность y | 2, 1, 3, 2, 3, 1, 3, 2, … |
| Плата / ПЛИС | DE1 / EP2C20F484C7 (Cyclone II) |
| Вход C | PIN_F15 |
| Входы D[3..0] | тумблеры SW9…SW6 |
| Сброс R | тумблер SW0 |
| Выходы Y[2..0] | красные светодиоды LEDR3, LEDR2, LEDR1 |

## Файлы

- `lab1.bdf` — схема верхнего уровня (два блока);
- `schetchik.v` — блок счётчика Джонсона;
- `rspsignals.v` — блок распределителя сигналов;
- `pins.tcl` — привязка выводов к элементам платы;
- `lab1.qpf`, `lab1.qsf` — проект Quartus II;
- `lab1.vwf` — входные воздействия для моделирования;
- `output_files/lab1.sof` — файл прошивки ПЛИС.
